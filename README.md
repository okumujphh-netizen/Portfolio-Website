# Lafeth Ogero - Portfolio Website

## Description

This is a personal portfolio website for Lafeth Ogero built as part of my software engineering learning journey at Moringa School.

The website showcases my background, technical skills, projects, and contact information. JavaScript is used to dynamically display my skills and projects on the webpage.

## Features

* Projects section generated using JavaScript
* Testimonials section generated using JavaScript
* Contact information
* GitHub profile link
* Responsive layout for different screen sizes
* Navigation links to different sections of the page

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Projects Featured

### Pet Store

A website for a pet store containing information about pets and services.

**Technologies:** HTML, CSS, JavaScript

### Akan Name Generator

A web application that generates an Akan name based on a person's date of birth.

**Technologies:** HTML, CSS, JavaScript

## What I Learned

While building this portfolio website, I learned how to combine HTML, CSS, and JavaScript to create a functional and interactive webpage.

I learned how to:

* Structure a webpage using HTML elements and sections.
* Style a webpage using CSS.
* Use JavaScript arrays to store multiple pieces of information.
* Use objects to organize related information about projects and testimonials.
* Use functions to perform specific tasks.
* Use `forEach()` to loop through arrays.
* Access HTML elements using `document.getElementById()`.
* Create new HTML elements using `document.createElement()`.
* Add content to HTML elements using `textContent`.
* Add elements to the webpage using `appendChild()`.
* Add CSS classes to dynamically created elements using `classList.add()`.
* Use template literals to combine text and JavaScript values.
* Dynamically generate project and testimonial sections using JavaScript.
* Connect JavaScript to an HTML webpage through the DOM.
* Organize a project using separate HTML, CSS, and JavaScript files.
* Use Git and GitHub to manage and share my project.

Most importantly, I learned how JavaScript can interact with the DOM to dynamically create and display content on a webpage instead of writing all of the content directly in HTML.
