# John Okumu and Eugene Ogero - Portfolio Website

## Description

This is my personal portfolio website for Lafeth Ogero built as part of my software engineering learning journey at Moringa School.

The website showcases my background, technical skills, projects, and contact information. JavaScript is used to dynamically display my skills and projects on the webpage.

## Features

- Personal About Me section
- Profile image
- Skills section generated using JavaScript
- Projects section generated using JavaScript
- Contact information
- GitHub profile link
- Responsive layout for different screen sizes
- Navigation links to different sections of the page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
